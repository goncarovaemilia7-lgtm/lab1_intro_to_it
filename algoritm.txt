Программа №1

Шаг 1. Подготовка и вспомогательные функции
Подключаются стандартные библиотеки для работы с потоками ввода-вывода (<iostream>) и строками (<string>).

Объявляется пользовательский манипулятор потока rub. Он принимает поток вывода, добавляет в него строку " руб." и возвращает измененный поток обратно. Это позволяет использовать конструкцию << rub для красивого форматирования валюты.

Шаг 2. Описание структуры данных (Класс Shop)
Создается шаблон для объектов типа «Товар» (класс Shop), который содержит:

Скрытые свойства (private): название товара (name), цена (price), производитель (manufacturer).

Открытые методы (public):

setData(...) — заполняет свойства товара переданными значениями.

getPrice() — возвращает цену товара для последующего сравнения.

display() — выводит на экран всю информацию о товаре в формате: Товар: [имя] | Цена: [цена] руб. | Производитель: [производитель].

Шаг 3. Инициализация данных (Начало функции main)
Создается массив items, состоящий из 3 объектов класса Shop.

Для каждого элемента массива последовательно вызывается метод setData, который жестко прописывает начальные данные:

Элемент 0: "Смартфон", 55000, "Samsung"

Элемент 1: "Ноутбук", 85000, "Asus"

Элемент 2: "Наушники", 15000, "Sony"

Шаг 4. Взаимодействие с пользователем
Программа объявляет переменную limit для хранения пороговой цены.

На экран выводится запрос: "Введите минимальную цену: ".

Программа переходит в режим ожидания и считывает введенное пользователем число в переменную limit.

Шаг 5. Фильтрация и вывод результатов
На экран выводится заголовок: "Товары дороже [limit] руб.:".

Запускается цикл for, который последовательно перебирает все 3 товара в массиве (индексы от 0 до 2):

На каждой итерации программа обращается к текущему товару и с помощью метода getPrice() узнает его цену.

Условие: Если цена товара строго больше введенного значения limit, то вызывается метод display(), и данные этого товара печатаются на экране.

Если цена меньше или равна limit, программа молча переходит к следующему товару.

Шаг 6. Завершение работы
После проверки всех трех товаров программа возвращает 0 и успешно завершает свою работу.

Программа №2
Текстовый алгоритм программы №2

Шаг 1. Описание структур данных
1. Объявляется класс Equation для представления квадратного уравнения. Класс содержит три вещественных коэффициента (k2, k1, k0) и конструктор для их инициализации.
2. Объявляется структура Roots, содержащая два вещественных поля (t1, t2) для хранения пары найденных корней.

Шаг 2. Описание функции решения уравнений (solve)
1. Функция принимает объект уравнения Equation и проверяет коэффициент k2. Если k2 равен 0, генерируется исключение runtime_error (уравнение не является квадратным).
2. Рассчитывается дискриминант по формуле: D = k1^2 - 4 * k2 * k0.
3. Проверяется значение дискриминанта. Если D < 0, генерируется исключение runtime_error (нет действительных корней).
4. Если проверки пройдены, вычисляются два корня по формулам: 
   t1 = (-k1 + sqrt(D)) / (2 * k2)
   t2 = (-k1 - sqrt(D)) / (2 * k2)
5. Функция возвращает заполненную структуру Roots.

Шаг 3. Ввод данных и начало защищенного блока (main -> try)
1. Внутри блока try объявляются переменные a и b для исходных данных.
2. Программа запрашивает у пользователя ввод чисел a и b.
3. Выполняется проверка потока ввода. Если пользователь ввел некорректные данные (например, текст вместо чисел), генерируется исключение invalid_argument.

Шаг 4. Расчет корней первого уравнения
1. Создается объект eq1 класса Equation с коэффициентами (1, -1, a).
2. Вызывается функция solve(eq1). Полученные корни сохраняются в структуру rx.

Шаг 5. Расчет корней второго уравнения
1. Создается объект eq2 класса Equation с коэффициентами (2, 1, -b).
2. Вызывается функция solve(eq2). Полученные корни сохраняются в структуру ry.

Шаг 6. Расчет финального выражения и проверка деления на ноль
1. Вычисляется знаменатель итогового выражения по формуле: denominator = (b - ry.t1) * (b - ry.t2).
2. Проверяется абсолютное значение знаменателя. Если оно близко к нулю (меньше 1e-9), генерируется исключение runtime_error о невозможности деления на ноль.
3. Если знаменатель валиден, вычисляется финальное значение z по формуле: 
   z = ((a - rx.t1) * (a - rx.t2)) / denominator.
4. Значение z выводится на экран.

Шаг 7. Обработка исключений (catch)
1. Если на любом этапе выполнения блока try было выброшено исключение, программа прерывает обычный ход работы и переходит в блок catch.
2. Текст ошибки выводится в поток сообщений об ошибках (cerr).
3. Программа завершает работу с кодом ошибки 1.

Шаг 8. Успешное завершение
1. Если код в блоке try выполнился без ошибок, программа возвращает 0 и успешно завершает работу.
